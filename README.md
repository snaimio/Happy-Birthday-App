## 📌 Technical Overview
This application demonstrates clean declarative UI development on Android. It leverages composable functions, modifier chains, and content scaling to deliver an immersive greeting experience across phone and tablet viewports.

### 💼 Technical Highlights
- **Declarative Composable Layouts**: Uses `Box`, `Column`, and `Row` composables with precise modifier constraints and layering.
- **Adaptive Typography & Theming**: Integrated Material 3 `Typography` scales with custom font families and dynamic color palettes.
- **Resource Management**: Type-safe string, drawable, and color resource handling via `stringResource()` and `painterResource()`.

## 🚀 Setup & Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/snaimio/happy-birthday-app.git
   cd happy-birthday-app
   ```
2. Open in Android Studio (Ladybug or newer) and run on an Android emulator or physical device (API 26+).
